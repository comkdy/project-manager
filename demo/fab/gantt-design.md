# 랏 일정 카드

## 데이터셋과 SQL

현재 간트는 `간트 · 일정 통합` 데이터셋을 사용한다. 카드 설정의 **일정 쿼리 관리**,
또는 데이터 관리에서 같은 데이터셋의 쿼리 관리를 열면 전체 조인 SQL을 수정할 수 있다.
SQL 편집·미리보기·수정 이력·새 버전 저장은 일반 데이터셋과 같은 경로를 사용한다.
원천 DB에 테이블이나 뷰를 만들지 않는다.

생성된 SQL에는 다음 작업이 모두 들어 있다.

1. lot_plan에서 프로젝트 lot_cd 범위와 `skip_yn <> 'Y'` 적용.
2. current_status를 조인해 WIP와 현재 공정·remark·현재 시작 시각 연결.
3. lot_his에서 공정 완료 시각과 이력 개수 계산 후 조인.
4. operation_tat를 비skip 계획과 연결. 같은 lot_cd/operation의 TAT 중앙값을 우선 사용하고,
   없으면 프로젝트 범위 내 전체 lot_cd의 동일 공정 중앙값으로 보완.
5. 각 계획 공정의 데이터와 TAT 표본 수·근거를 출력.

`gantt.data_mode=dataset`인 카드의 서버 실행 경로는 위 데이터셋의 결과만 사용한다.
서버에서 물리 테이블을 다시 찾아 조인하거나 컬럼명을 별도로 지정하지 않는다.
작성 SQL은 기존 읽기 전용 검증/실행 경로를 그대로 사용하고, 바깥에서 랏 검색·페이지와
표시 플래그만 적용한다. 기간 설정은 그리는 범위만 바꾸고 완료 이력을 자르지 않는다.
기존 tables 방식 카드는 호환 조회를 유지하며 편집 화면에서 **조인 SQL 데이터셋 만들기**로
변환할 수 있다. 새 카드 저장은 조인 데이터셋 모드로 한다.

원천 컬럼명·테이블명은 SQL에서 변경할 수 있다. 마지막 출력 이름은 아래 계약을 유지한다.
예: `p.new_lot_column AS lot_id`. 필터용 컬럼은 자유롭게 추가할 수 있다.

| 출력 이름 | 의미 |
|---|---|
| lot_cd, lot_id | 랏 식별자 |
| operation_seq, operation | 계획 순서, 공정명 |
| current_operation | 해당 랏의 현재 공정명 |
| current_started_at | 현재 공정 시작 시각. 없으면 NULL::timestamptz |
| remark | 랏 특이사항 |
| completed_at, history_count | 완료 시각, 공정 이력 개수 |
| expected_hours | 해당 공정 자체의 예상 TAT, 시간 단위 |
| tat_samples, tat_basis | 표본 수, same_lot_cd / all_lot_cd / unavailable |

operation_seq, history_count, expected_hours, tat_samples는 숫자형이고 시각 출력은
날짜/시간형이어야 한다. 같은 랏 내 중복 순서·중복 공정·중복 완료 이력은 명시적으로
거절한다. 반복 공정에 대한 원천 키 확장은 별도 설계가 필요하다.
현재 시작 시각이 없으면 직전 실제 완료 시각으로 추정한다. 시작 미상·TAT 미상·소요 초과는
미래 시점을 만들어 내지 않는다. 예시 카드는 고정 WIP와 맞춘 2026-10-22 00:00 UTC
스냅샷이며 운영 데이터는 고정 시점을 해제해 사용한다.

## 두 표시 필터

- **시작선 표시 필터**: 모든 조건을 만족하는 공정 시작점에 세로선 표시.
  기본값은 `area_id NOT IN ('VIRTUAL','CNC') AND samp_seq=0 AND main_oper_yn='Y'`.
  빈 목록은 모든 공정에 시작선을 표시한다.
- **핵심 공정 필터**: 모든 조건을 만족하는 공정에 띠 위 깃발과 공정명 표시.
  시작선 조건을 만족하지 않아도 표시하며, 빈 목록은 깃발 없음이다.
  예시 카드는 oper A/B/C/D, 각 CD 측정 공정과 EPM을 선택해 두었다.
- 각 목록 내 조건은 AND. IN/NOT IN으로 여러 공정·그룹을 지정할 수 있다.
  값은 바인드 파라미터로 전달하며 SQL 문자열에 끼워 넣지 않는다.
- 두 필터는 전체 비skip 일정 계산을 마친 뒤 표시에만 적용한다.
  어떤 선/깃발도 매칭하지 않아도 랏과 전체 일정 띠는 유지한다.

띠의 시간 구간은 서버가 전체 경로로 계산한 ribbon 데이터로 전달한다.
숨겨진 중간 공정과 마지막 주요 공정 뒤의 숨겨진 꼬리도 전체 종료까지 이어진다.
색상은 완료(회색) / 진행 중(청록) / 예상(옅은 청록)이며 상태가 같은 채움은 합친다.
선·깃발 툴팁은 공정명, 예상 도달 시간, 해당 공정 자체의 예상 TAT 세 항목이다.
숨겨진 공정의 TAT를 툴팁에 합산하지 않는다.

깃발은 띠 위 두 줄에 겹치지 않게 놓는다. 밀집 구간은 이름 +N으로 묶으며 툴팁에서
묶인 공정을 확인하고 클릭하면 상세 목록으로 이어진다. SVG 내에 표시해 내보내기에도 포함한다.
모든 선·깃발은 키보드 포커스와 Enter/Space 활성화를 지원한다.

시간축은 카드 너비에 맞추며 가로 스크롤이 없다. 12시간/3일/1주/전체 범위와 왼쪽 버튼
드래그 이동을 지원한다. LOT/현재 공정·시간축 헤더는 세로 스크롤 시 고정한다.
UI 드래그는 데이터 재조회 없이 표시 좌표만 바꾼다. 대시보드의 1분 갱신/동일 요청 공유
캐시는 그대로 사용한다. 서버는 최대 50개 랏과 75,000개 전체 공정으로 조회량을 제한한다.

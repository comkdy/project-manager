# 첫 기능 묶음 구현 및 검증 결과

검증일: 2026-10-23 (Asia/Seoul)

## 구현 범위

### 공통 / 프로젝트 구분

- 데이터 관리 목록·제목, 데이터셋 편집, 일반/Python/간트 카드의 데이터셋 선택, 지식 수집의 데이터셋 선택에 공통 배지를 적용했다.
- 프로젝트 전용 데이터셋은 프로젝트 이름을 함께 표시한다.
- 배지는 데이터셋 정의의 소속을 뜻한다. 실제 조회 행의 범위는 기존 프로젝트 필터와 SQL 규칙을 따른다.

### 데이터셋 변경 영향 미리보기

- 기존 데이터셋을 저장하기 전에 컬럼 추가·삭제·타입 변경과 연결 대시보드/카드의 영향을 확인한다.
- 카드별 결과를 호환 가능 / 검토 필요 / 호환되지 않음으로 구분한다. 기존 오류와 이번 변경으로 생긴 오류를 구분해 설명한다.
- 호환되지 않는 카드가 있으면 명시적으로 확인해야 저장할 수 있다.
- 검토한 쿼리·이름·프로젝트·버전이 바뀌거나 미리보기가 실패하면 이전 결과로 저장할 수 없다. 동시 수정은 최신 버전을 확인하고 재검토한다.
- 이전 버전 복원도 현재 최신 버전과 비교하고 새 버전으로 저장한다.
- 미리보기는 읽기 전용이다. 카드, 데이터셋 버전, 감사 기록, 캐시를 변경하지 않는다.
- 서버 응답 모델에서 화면용 타입을 생성하며 동기화 검사를 추가했다.

### 분석 → 질문 → 승인 → 분석 재개

- 분석 결과에서 해당 질문으로, 질문에서 해당 답변의 검토 초안으로 직접 이동한다.
- 승인 후 원래 질문과 분석으로 돌아가 기간·측정 계열·프로젝트·반복 측정 조건 등을 복원한다.
- 승인된 설명을 보여주고, 사용자가 수치 조건을 입력하고 승인 지식을 근거로 선택한 뒤 분석을 실행한다.
- 완료된 분석의 조건을 다시 불러올 때도 기존 승인 지식 참조를 유지한다.
- 화면 전환 중 답변 및 검토 메모를 보존한다. 숨겨진 화면의 대화상자와 불필요한 반복 조회는 중지한다.
- 작업공간/사용자/권한 변경, 오래된 승인 버전, 잘못된 질문·답변 연결을 확인한다. 늦게 도착한 조회 응답이 새 입력을 덮어쓰지 않도록 차단했다.
- 기간 복원 시 초·소수초와 원래 요청의 시간대 표현을 보존한다.

## 실제 브라우저 연계 검증

별도 임시 메타데이터 DB와 로컬 읽기 전용 원천을 사용했다. 검증용 공통/프로젝트 데이터셋, 대시보드, 질문, 답변, 초안을 생성했다.

1. 공통 데이터셋과 프로젝트 전용 데이터셋이 함께 보이는 화면에서 배지와 이름을 확인했다.
2. `value` 컬럼 삭제를 미리보기했다. 대시보드 2개, 카드 4개 중 평균 카드 2개는 비호환, 행수 카드 2개는 호환으로 표시됐다. 확인 전 저장 버튼이 비활성화됐고 취소 시 편집 내용이 유지됐다.
3. 호환되는 컬럼 추가를 v2로 저장했다. 연결 대시보드의 평균·행수 카드가 v2를 사용해 표시됐다.
4. 이전 v1을 복원하면서 v2 대비 변경 영향을 확인하고 v3으로 저장했다.
5. 기준이 빠진 분석의 정확한 질문과 초안으로 이동했다. 검토 메모를 입력한 뒤 화면을 왕복해도 메모가 유지됐다.
6. 검증용 초안을 승인하고 원래 분석으로 복귀했다. 승인 설명은 표시되고 미정 수치 입력란은 빈 상태로 유지됐다.
7. 최소 표본 3, 변화량 0.5를 입력하고 승인 지식 v1을 연결해 재분석했다. 37,251행 분석이 완료됐으며 판정이 ‘기준 미만’으로 표시됐다.
8. 저장된 요청을 대조해 기간의 초·소수초를 포함한 기존 조건이 동일하고 원래 분석은 변경되지 않았음을 확인했다. 새 결과에 승인 지식 참조가 기록됐다.
9. 완료된 새 분석에서 ‘조건 불러오기’를 실행해 승인 지식 참조 유지도 확인했다.
10. 실제 앱에서 프로젝트 3개·데이터셋 13개가 정상 조회되고 공통 배지가 표시됨을 확인했다. 최종 브라우저 콘솔 오류/경고는 없었다.

임시 검증 서버를 종료하고 임시 메타데이터 DB를 정리했다. 실제 앱은 최신 서버와 화면으로 실행 중이다.

## 검증 범위와 한계

- 영향 미리보기는 현재 컬럼 구조와 카드 설정에 대한 정적 검사다. 데이터 값의 의미, Python 실행 결과, 모든 실행 시 오류를 보장하지 않는다. 한 오류를 수정한 뒤 추가 오류가 드러날 수 있다.
- 영향 검토 이후 다른 사용자가 대시보드를 변경하는 경우까지 대시보드를 잠그지는 않는다. 데이터셋 버전 충돌은 차단한다.
- 승인된 자연어 설명을 수치로 자동 변환하거나 자동 실행하지 않는다. 사용자가 기준을 확인하고 명시적으로 실행한다.
- 브라우저 검증은 로컬 관리자 모드에서 진행했다. 답변 추출 초안은 고정 검증 자료를 사용했으며 외부 LLM 호출과 외부 SSO 로그인은 수행하지 않았다. 관련 서버 회귀 검사는 전체 검사에 포함됐다.

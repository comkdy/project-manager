# 관리 데이터 백업·복구 준비 검증

작업일: 2026-10-24 (Asia/Seoul). 중단되었던 다음 우선순위 묶음인 관리 데이터 백업·임시 복원 검증과 관리자 준비 상태 화면을 완료하고 현재 앱 `http://127.0.0.1:8000`에 반영했다.

## 구현과 사용

관리자는 **작업 상태 → 백업·복구 준비**에서 관리 DB 전체를 백업하고 실제 임시 복원을 검증한다. 프로젝트 선택과 무관하게 모든 원천 DB의 관리 기록이 대상이다. 진행 단계, 저장 시점, 검사 결과, 파일 보관 경로를 표시하며 저장된 백업의 재검증을 제공한다.

- PostgreSQL의 일관된 스냅샷으로 `public.app_*` 관리 데이터와 시퀀스를 보관한다. 원천 측정값·브라우저 초안·암호화 키·설정 파일은 제외한다.
- 파일 무결성, 임시 DB 실제 복원, 전체 테이블 행 수·내용 해시, 분석·질문·승인·일정·재시도·비교·알림 연결, 현재 암호화 키 해독을 검사한다.
- 임시 복원본의 예약 및 대기·처리 중 작업만 중단하고 임시 DB를 제거한다. 원래 DB는 변경하지 않는다.
- 관리자 실제 권한과 작업공간을 재확인한다. 관리 DB 잠금으로 중복 실행을 방지하며, 반복 검증 후에도 이전 생성 요청의 멱등성을 유지한다.
- 중단 기록 감지, 파일 변조·경로 이탈 차단, 무관한 DB 정리 거절, 비밀 값 오류 노출 방지, 최대 50개 보관·최근 20개 표시를 구현했다. 자동 삭제는 없다.
- 생성 계약 검사에 `recovery_contract.py`와 `recovery.generated.ts`를 추가했다. 기존 데이터 모델 변경이나 마이그레이션은 없다.

사용·운영 범위: `METADATA_RECOVERY.md`. API: `CONTRACT.md`.

전체 검사 후 저장 경로 경계와 프로젝트 번호 시퀀스 보존 검사를 보완하고 영향 영역을 다시 실행했다. 화면에서 닫히는 대화상자의 제목이 순간적으로 바뀌던 부분도 수정한 뒤 다시 타입 검사·빌드하고 실제 앱에서 실행했다. 검사 건수는 중복되므로 합산하지 않는다. 기존 테스트 클라이언트 사용 중단 예정 경고와 Plotly 번들 크기 경고는 남아 있다.

새 검사에는 관리자/편집자/조회자 권한, 권한 회수, 작업공간 전환, 요청 재전송·다른 동작 ID 재사용, 동시 잠금, 보관 한도, 중단 상태, 지원하지 않는 DB, 경로 경계, 변조 파일, 안전한 임시 DB 정리, 오류 비밀 값 비노출, 잘못된 암호화 키를 포함한다. 실제 PostgreSQL 검사에서는 처리 중 답변·분석과 예약을 복원본에서만 중단하고 원래 상태가 유지되며, 시퀀스 값도 보존되는 것을 확인했다.

## 실제 흐름과 브라우저

분리된 임시 관리 DB와 읽기 전용 `wafer_fab_demo`, 고정된 검증용 AI 응답 어댑터를 사용했다. 실제 HTTP API 및 worker/scheduler에서 다음을 확인했다.

1. 완료 분석 → 정기 일정 → 실행 중 취소 → 결과 폐기 → 원래 조건·기간·일정·비교 연결로 재시도 완료.
2. 이력에 원래 분석·취소·재시도 기록 보존.
3. 실제 질문의 답변 초안 승인 → 승인 버전과 명시적인 수치 조건으로 37,251행 재분석 → 기존 일정 조건 교체.
4. 과거 비교 대상과 근거 행 보존.
5. 프로젝트의 이동 기간에서 측정 계열이 누락되었을 때 변화 알림 생성, 정확한 이전 결과와 근거 비교, 알림 확인 후에도 근거 보존.
6. 위 데이터가 담긴 30개 테이블·64행 백업 및 실제 임시 복원, 재검증, 원래 생성 요청 재전송 시 중복 없음.
7. 백업 전후 분석·질문·승인·일정·이력·비교·알림·대시보드·프로젝트/데이터셋 응답 동일.

결과: `feature-bundle-7-qa.json`. 브라우저에서도 백업 생성·진행 중 버튼 제한·재검증·결과 펼치기, 프로젝트 변경 후 동일한 관리 DB 백업 유지, 백업 후 기존 알림의 비교 표 접근을 확인했다. 브라우저 오류·경고 로그는 없었다.

검증 종료 후 임시 앱, 그 프로세스가 만든 임시 관리 DB, 검증 전용 백업 폴더를 정리했다. 실제 앱 백업은 보관했다.

## 범위와 남은 운영 준비

이 기능은 현재 작업공간의 관리형 로컬 PostgreSQL을 지원한다. 실제 DB 덮어쓰기나 자동 서비스 전환, 원천 DB 복구, 외부 저장소 복사, 암호화 키 자동 보관을 수행하지 않는다. 백업 파일 자체는 암호화하지 않으며 OS 폴더 권한을 따른다. 현재 PC에서 검증에 통과했어도 암호화 키와 외부 보관은 별도 준비가 필요하다. 실제 사내 SSO·외부 AI 품질은 이번 검사 대상이 아니다.

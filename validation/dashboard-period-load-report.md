# 대시보드 기간 필터 및 부하 검증 — 2026-10-21

히트맵을 제거하고 대시보드 조회 시작을 ISO 연도·주차로 선택하도록 변경했다. 기본은 현재 주를 포함한 최근 4주이며, 월요일 00:00 한국 시간부터 조회한다. 날짜/시간대 없는 timestamp는 같은 달력 날짜로 비교한다. 종료일 제한은 두지 않는다.

카드 구성 → 세부 설정 → 필터의 **공통 기간 적용**을 끄면 카드만의 시작 연도·주차를 지정한다. 해당 설정은 카드와 함께 저장된다. 대시보드 공통 선택은 브라우저 탭 세션 안에서 DB·프로젝트별로 유지된다. 최근 4주 버튼으로 현재 기준 기본값을 다시 적용할 수 있다.

기간 기준 컬럼은 원천 테이블/뷰의 날짜·시간 타입에서 찾는다. 주 원천에 후보가 하나면 자동 선택하고, 여러 후보가 있으면 카드 설정에서 선택한다. 날짜 컬럼이 없거나 명확하지 않을 때 무제한 조회로 대체하지 않고 안내한다. SQL 편집기의 저장된 원문과 데이터 관리 조회는 그대로 유지한다. 대시보드에서만 선택한 원천을 기간으로 제한한 뒤 저장된 SQL과 카드의 집계를 실행한다. CTE, JOIN, UNION, 집계 쿼리를 검증했다. 선택한 원천이 DB 뷰이면 그 뷰 경계에 필터가 적용되며, 뷰 내부로 조건을 내려보낼지는 PostgreSQL 실행 계획에 달려 있다.

## 서버 동시 조회

- 사용자 DB와 분리된 임시 PostgreSQL DB에서 측정하고 종료 후 삭제했다. 실제 앱의 HTTP·인증·메타데이터·쿼리 경로를 사용했다. 로컬 PC, 앱 worker 1개, 기본 연결 풀 설정이다.
- 20주에 걸친 3,190,500건: Inline 2,100,000, WAT 27,000, EDS 1,063,500. 별도로 Wafer 1,500개.
- 최근 4주에는 측정값 638,100건, Wafer 300개가 해당한다. 입력 기간 범위가 80% 감소했다.
- 사용자마다 카드 7개를 동시에 요청했다. 각 조건을 3회 반복했다. 동시 클라이언트가 같은 로컬 테스트 관리자 권한으로 접속하며, 사내 SSO 및 네트워크 지연은 포함하지 않는다.
- 캐시 초기화 조건은 각 동시 조회 묶음 시작 전에 앱 결과 캐시를 비운다. 같은 묶음 안에서는 먼저 완료된 조회의 캐시를 공유한다. DB/OS 캐시는 따뜻한 상태다. 재사용 조건은 미리 동일한 보드를 조회했다.

아래 시간은 **사용자 한 명이 카드 7개 응답을 전부 받는 시간**이다. 화면 렌더링은 포함하지 않는다.

총 1,575건의 측정 요청에서 오류가 없었다. 최근 4주 보드 응답 크기는 평균 약 498KB로 전체 범위의 약 577KB보다 14% 작았다. 분포 차트는 최근 4주에도 표시 한도 20,000행에 도달한다. 표시 한도는 정확한 전체 분포를 보장하는 무작위 표본이 아니다.

이번 데이터에서는 기간을 줄였다고 서버 응답이 빨라지지는 않았다. 원천 뷰의 내부 집계와 앱의 동시 요청 처리/직렬화 비용을 별도로 분석해야 한다. 5명 사용은 비교적 짧은 응답이지만 30명이 동시에 여는 경우 약 6초의 대기가 남는다. 실제 사내 DB의 인덱스·뷰·카드 수·서버 성능·서로 다른 조회 조건에 따라 달라지며, 장시간 지속 부하나 사내 환경의 성능 보장으로 해석하지 않는다.

## 브라우저 렌더링

실제 Plot 컴포넌트를 사용하는 별도 검증 페이지에서 KPI 2개와 차트 5개를 렌더링했다. 산점도 20,000점, 분포 20,000행, 막대 3개, 선 60개, Wafer 709점을 합성 응답으로 전달했다. DB 조회는 제외했다.

3회 결과는 **766ms / 728ms / 748ms**였다. 페이지 컴포넌트 로딩 후 Plotly 로딩·렌더링을 측정하고, 모든 차트의 SVG가 생성된 뒤 마지막 화면 변화 후 150ms까지 포함했다. 여러 사용자의 브라우저를 한 번에 구동한 결과는 아니다. 이번 로컬 조건에서는 브라우저 그림 그리기보다 30명 동시 API 응답 대기가 더 컸다.

## 재현

서버 부하 테스트는 프로젝트의 관리된 로컬 데모 클러스터만 허용한다. 매번 별도 임시 DB를 생성하며 기존 DB 연결 설정과 앱 프리셋은 수정하지 않는다.

```powershell
.venv\Scripts\python.exe validation/dashboard_load_test.py
```

```powershell
node node_modules/vite/bin/vite.js build --config validation/vite.config.ts
```
